---
title: <PlusModalPage />
description: Component to use for rendering a modal page.
---

This component uses [`<PlusParallelPage />`](/components/plus-parallel-page) at the underlying level for implementation but enables `hide-fallback` by default.

It also only renders while a modal route is open (see [`ModalRouter.isOpen`](/api/interfaces#modalrouter)), i.e. when the modal was opened through [`<PlusModalLink>`](/components/plus-modal-link) or [`$modalRouter`](/api/composables#usemodalrouter). A route reached by direct navigation (entering the URL, refreshing, or a plain `NuxtLink`) renders as a plain full page and this outlet stays empty — even while a pending navigation still displays the previous page. If you need a parallel outlet that renders regardless of the modal state, use [`<PlusParallelPage />`](/components/plus-parallel-page) directly.

## Usage

::note
Feel free to read [Modal Routes](/routing/modal-routes) first to know how to setup Modal Routes.
::

```html [pages/index.vue]
<template>
  <div>
    <PlusModalPage name="foo" />
  </div>
</template>
```
